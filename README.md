#### ⚡ [Saudi-Fix v2.0](https://github.com/Scrim-Fix/Saudi-Fix)

Windows 10 / 11 optimization utility for gaming PCs and laptops. A single native Batch file: no installer, no downloads, no dependencies.

| Section | What it does |
| --- | --- |
| Process & Services | svchost grouping by installed RAM (typically 30–50 fewer processes), telemetry tasks, unused services |
| FPS & Gaming | Game Mode, GPU / CPU priority for games, true fullscreen, network latency tweaks |
| Input Latency | Mouse acceleration off, USB power saving off |
| Clean & Memory | Temp files, shader cache, update cache |
| Power & CPU | Custom power plan, core parking, power throttling (skipped on laptops by default) |
| Debloat & System Tools | Ads, tracking and bloatware removal · TRIM, SFC, DISM, network reset |

**Safety by design:** a restore point on every launch, registry backup on first run, the original value of every service and setting saved before it changes, a full change log, and per-section revert.
